### Featured Projects

**[Franka Gazebo RBF Adaptive Control](https://github.com/hengsleep/Franka_Gazebo_RBF_adaptive_control_Prj)**\
CTC control with online RBF neural-network adaptive compensation for robust trajectory tracking of a 7-DOF Franka FR3 manipulator under model uncertainty, implemented and evaluated in Gazebo + ROS 2.

**[RBF Sigma Adaptive Robot control](https://github.com/hengsleep/RBF_Sigma_Adaptive_Robot_control_Prj)**\
A nonlinear adaptive control framework for uncertain multi-joint robotic manipulators using radial basis function (RBF) neural networks for online uncertainty approximation.

**[DARA Lipschitz Continuous](https://github.com/hengsleep/DARA_Lipschitz_continuous_Prj)**\
Distributed Adaptive Resource Allocation for multi-agent systems over directed graphs, requiring only Lipschitz continuous local cost functions.
